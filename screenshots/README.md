# Screenshots

How these images were captured, for regenerating them later.

## Tool

[ShareX](https://getsharex.com/)

## Capture setup

1. Set the Command Palette (or desktop behind it) background to solid black (`#000`).
2. Capture with ShareX using **Ctrl + Print Screen**.
3. Right-click the captured image and choose **Beautify image**.
4. Apply the effect settings below.

## ShareX effect settings

| Setting | Value |
| --- | --- |
| Margin | `50px` |
| Padding | `0px` |
| Rounded corner | `14px` |
| Background | Gradient `#FF512F` → `#DD2476` |

### Shadow

| Setting | Value |
| --- | --- |
| Radius | `30px` |
| Opacity | `80%` |
| Distance | `10px` |
| Angle | `180deg` |
| Color | Black |
